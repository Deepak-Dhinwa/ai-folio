# deepakdhinwa.me

Personal site for Deepak Dhinwa. Next.js, hosted on Vercel.

```bash
npm install
npm run dev
```

Open http://localhost:3000.

The public resume button points at the Google Drive file. `public/resume.pdf` is a local copy of the same one-page PDF.

## Publishing

`main` is the live site. Any other branch is a preview only, so a change does not replace deepakdhinwa.me until it is merged into `main`.
